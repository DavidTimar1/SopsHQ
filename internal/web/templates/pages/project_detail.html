About this project page (secrets, paths, assignments & security)
The three sections
  • Folder paths - where this project's folder lives on each machine. SopsHQ writes .sops.yaml into the local path on Apply.
  • Key assignments - which key is granted to which OS user on which machine; this drives both the list of public keys and key placement.
  • Secrets - the name/value pairs encrypted into this project's secrets.yaml. Values are hidden; click Show to reveal one. SopsHQ keeps NO copy of a value - it encrypts straight into the file and forgets it.
Order of operations

Set a folder path -> wire or assign a key -> Apply (writes .sops.yaml and places the key) -> add and edit secrets.

Security note

Revealing or editing a secret decrypts it on this machine and sends it to your browser over the encrypted connection only - it is never written to a log, an audit row, or a URL. The reveal action itself is audited by secret NAME only. A value never leaves this machine and is never replicated to other machines.
