About this page

What this page is. A single place to browse all of SopsHQ's records at once - Keys, Projects, Machines, OS users, and Assignments (plus Users and Secrets for admins). Each tab is its own sortable, searchable, filterable table. It is read-only: to add, edit, or delete a record, use that record's own page.

Security. Every table shows names and metadata only - never a private key, the vault key, a TOTP secret, or a decrypted secret value. The Secrets tab reuses the same value-free catalog as the Secrets page (no value column, no reveal), and it - like the Users tab - is shown to admins only.
