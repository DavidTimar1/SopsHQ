About the audit log (security)
What this page is

An append-only record of actions taken through the panel: who did it, what they did, which target it touched, and whether it succeeded, failed, or was denied. Revealing a secret value is recorded too (as secret_reveal, by NAME only).

Security note

The log identifies things only by NAME or UUID. It never contains a private key, a vault key, an authenticator secret, or a decrypted secret value - so the audit trail itself is safe to read and keep.
