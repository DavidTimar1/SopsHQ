Usage (best-effort)

Decrypt events that machines have reported - typically from the optional sops shim. SopsHQ is a management plane, not a decrypt gateway, so this is best-effort and bypassable, and each machine only reports its own. Use Install usage shim below to set it up (or install from shims/ by hand).

About usage & why it is "best-effort"
What this page is

A log of times a key was used to DECRYPT something, as reported by the machines themselves. It helps answer "is this key still in use?" before retiring it.

Why it is not authoritative

SopsHQ is never in the decrypt path - once a key is placed, sops -d runs entirely locally without asking SopsHQ. So usage is only visible if a machine volunteers it through the optional sops shim (a thin wrapper that reports each decrypt). Anyone can decrypt without the shim, so a blank or low count does NOT prove a key is unused.

Security note

Reports record the file path and which keys were attributed - never the decrypted values. Use the Install usage shim button below (or the scripts in shims/) to start populating this.
