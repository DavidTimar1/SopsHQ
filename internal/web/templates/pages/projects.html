Projects

A project is a folder whose secrets are encrypted to one or more public keys. Open a project to set its folder path per machine, assign keys, and edit secrets.

About projects & how to get one working
What a project is

A project is just a folder on your machines that contains an encrypted secrets.yaml and a .sops.yaml rules file. SopsHQ tracks which keys encrypt that project's secrets and writes those two files for you.

Steps to make a project usable
  • Add the project here (name + optional note).
  • Open it and set its folder path on each machine.
  • Wire it (one click) - SopsHQ generates a shared key, assigns it, and writes .sops.yaml - or assign existing keys yourself.
  • Apply from the dashboard to place the key and write the files; then you can add secrets.
Security note

The folder path points at real directories on real machines. SopsHQ writes .sops.yaml there and (on Apply) re-encrypts the secrets file. If the folder already contains a hand-made key or .sops.yaml, wiring stops and asks you to reuse or replace it, so other projects' secrets are never silently broken.
