Secrets

About this page (every secret, grouped by value)

This page lists every secret SopsHQ can read on this machine, across all projects and global (shared) sets, grouped by identical value - so you can see where each value is used and spot duplicates.

  • Each row is one use of a secret: its masked Value (click Show to reveal just that one), its Name, the Project or Global Set it belongs to (a global-set secret shows a dash for Project; its set name appears in the Global Set column), the Machine / User / Key / Path where the encrypted file lives, and Uses - how many places share that same value.
  • The table sorts on any column (click a header) and has a search box plus per-column filters - sort by Uses to spot values reused across projects.
Security note

SopsHQ keeps NO copy of a secret value. To group identical values, building this page decrypts each project's and global set's secrets.yaml in memory using the keys SopsHQ holds, groups the values, then discards the plaintext - nothing is written to disk or logged. The page is admin-only; values stay masked until you click Show, and each reveal is audited by secret NAME only (never the value). Projects or sets this machine cannot decrypt are not shown (their values never leave their own machine). Manage global sets (create, add/remove secrets, users) on the Global page.
