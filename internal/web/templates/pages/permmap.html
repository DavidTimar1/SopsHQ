Permissions

A read-only audit of who can access what across this Linux machine's filesystem: ownership, octal mode, special bits, POSIX ACLs, and file capabilities. Find world-writable, dangerous, ACL'd, and ACL-override paths; browse the folder tree; and see what changed since a baseline. It never changes any permission.

About this page

What this page is. A whole-server permission map. It runs the standard Linux tools (find, getfacl, getcap) over chosen directory roots and records, for every path, the owner, owning group, mode (with setuid/setgid/ sticky), any named ACL entries, and file capabilities - then flags the security-relevant ones.

The four queries. World-writable (anyone can write), Dangerous (world-writable non-sticky paths plus setuid/setgid), Has ACL (a named user/group beyond owner/group/other), and ACL override (a named principal granted access beyond the owner and owning group). Plus free-text search and a folder tree.

Drift. Set a baseline, and each day SopsHQ re-scans, compares, and (if you opted in under Notifications) sends a digest of what changed - added, removed, and the before->after of each changed attribute. It is read-only; it never fixes anything.

Security. The map reveals the full filesystem layout and who can access what, so this page is admin-only, the data is machine-local (vault-sealed, never replicated to the other machine), and the scan runs as a dedicated, locked-down user with read-only sudo - not as SopsHQ itself.
