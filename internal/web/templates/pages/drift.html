Drift

Differences between what SopsHQ intends and what is actually on disk on this machine (a key never placed, a hand-edited .sops.yaml, a stale key after a rotation elsewhere). Fix drift by running Apply from the dashboard.

About drift & why it matters
What drift is

"Drift" is any gap between the setup SopsHQ has recorded (the intended state) and the real files on this machine. It is read-only - looking here changes nothing.

What it catches
  • A key that was assigned but never placed on disk.
  • A .sops.yaml whose public keys no longer match what is intended (for example after a key was rotated on another machine).
  • A placed key that is stale compared with the current one.
How to fix it

Run Apply (here or from the dashboard). The header shows a red alert whenever there are pending changes to apply, on this or any machine.

Security note

Drift detection only reads public facts (which files exist, which public public keys a .sops.yaml lists). It never displays private keys or secret values.
