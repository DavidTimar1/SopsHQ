Map

Drill down a nested folder tree to see how SopsHQ's records relate - which secrets live under which path, on which machine, in which project, and so on. Pick a built-in view, or build your own by ordering the grouping levels. Names and ids only - never a secret value.

About this page

What this page is. The other pages each show one record type (Keys, Projects, Machines, ...). The Map view shows how those records relate, as an expandable tree. Each view is one grouping order: for example Project -> Machine -> Path -> Secret name groups every secret under its path, machine, and project.

Left pane is the tree: click a folder to expand or collapse it; click a leaf item to load its details on the right pane. The detail pane is read-only - to change a record, open its own page (a project leaf links to the project page).

Make your own. Press + New view, name it, tick the grouping levels and order them with the up/down arrows, choose the leaf level, and save. Custom views are stored records, so they survive restarts and sync to the other machine.

Security. The tree carries names and ids only - never a private key, the vault key, a TOTP secret, or a decrypted secret value. A Secret-name node shows the NAME of a secret, never its value.
