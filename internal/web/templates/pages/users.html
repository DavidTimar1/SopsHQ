Panel users

About panel users, roles & 2FA recovery (security)
What this page is

These are LOGIN accounts for the admin panel itself - separate from the OS users that hold keys. Only admins see this page.

Roles
  • admin - full control: machines, keys, users, applying and pushing changes.
  • developer - day-to-day work such as rotating keys they are assigned; cannot manage panel users.
Sign-in & two-factor

Every login needs a password AND a six-digit code from an authenticator app. A new user is sent to set up their authenticator at first login. If someone loses their authenticator they can use a one-time recovery code, or an admin can Reset 2FA here to let them enroll a fresh one.

Security note

Passwords and recovery codes are stored only as salted PBKDF2-HMAC-SHA384 hashes; the authenticator secret is encrypted in the vault. SopsHQ never shows or logs any of these. Resetting 2FA invalidates the old authenticator and recovery codes immediately.
