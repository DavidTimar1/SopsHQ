Machines

Each machine in your cluster runs SopsHQ. Mark the one this panel runs on as this machine; add the others (peers) by their Tailscale address. Two machines sync when they use the same vault key (so each can read the other's keys) and the same transfer key (which authenticates the connection). Each physical machine is one record: SopsHQ never creates a second one for the same machine, and when a brand-new machine appears while you already have a peer it asks whether it is a new machine or a reinstall of an existing one.

About linking two machines

Same vault key. The vault key is derived from your vault key, so using the same vault key on both machines means each can decrypt the keys it syncs from the other - nothing else to exchange.

Transfer key. A shared secret you set on both machines (below). It authenticates machine-to-machine requests; the traffic itself rides your encrypted Tailscale network. Set it, then add each machine on the other by its Tailscale address.

No certificates. There are no certs or fingerprints to copy - just the vault key, the transfer key, and each machine's URL.
